# EVERYDAY builds

The EVERYDAY game reads content from here: test APKs, and the content packs the game downloads and updates by itself
(`packs/manifest.json` lists them). Build outputs only; no source code.

## Install on Android (test builds)

1. On the phone, open https://github.com/alexokoji/everyday-builds/raw/main/apk/everyday-latest.apk and download it.
2. Open the downloaded file. Android asks to allow installs from this source (your browser or file manager): allow it.
3. Open EVERYDAY. The first time it downloads the game content (about 95 MB; Wi-Fi recommended). Later updates download only what changed.

Needs a 64-bit Android phone (almost every phone since 2017). Updating: install the newer APK over the old one; your saved content stays.
